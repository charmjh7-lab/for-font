# For Font

S펜으로 영어·한글 글꼴을 만드는 작은 Android 앱. Android 8.0 이상 / 서버·로그인·인터넷 권한 없이 기기 안에서 작동합니다.

## 사용

1. 위쪽에서 글자 묶음을 고르고 표시된 글자를 아래 흰 칸에 씁니다. 손가락과 손바닥은 잉크로 기록하지 않습니다.
2. 태블릿에서는 비교 글자와 현재 글자를 동일한 배율·기준선으로 나란히 봅니다. 세로형 폰 화면에서는 작은 비교 영역이 위쪽에 배치됩니다.
3. 비교 영역 또는 **비교** 버튼으로 작성한 글자를 고정합니다. **겹쳐 보기**로 현재 칸에 같은 좌표의 옅은 참고 획을 표시합니다.
4. **다음**, **안 쓴 글자**, **글자 찾기**로 이동합니다. 획마다 자동 저장하며, 실행 취소·복원과 획 지우개를 제공합니다. S펜 버튼을 누른 채 새 획을 시작하면 임시 지우개가 됩니다.
5. **내보내기**에서 실제 TTF 또는 다시 편집할 수 있는 `.forfont` 원본을 저장합니다. 원본 가져오기는 현재 작업을 교체하므로 안내창을 먼저 표시합니다.

한글은 114자 시작 묶음, 완성형 11,172자 전체, 호환 자모 51자를 지원합니다. 완성형 글자는 한 글자씩 직접 작성하며 자모로 자동 합성하지 않습니다. 영문 대문자·소문자, 숫자·기호를 제공합니다. 작성하지 않은 글자는 TTF에 넣지 않습니다. 공백은 자동으로 포함합니다.

기준 좌표는 1,000 em, 위선 y=100, 소문자 높이 y=300, 기준선 y=800, 아래선 y=950입니다. 좌우 보조선은 x=100/900입니다. 영문은 왼쪽 보조선에 맞춰 쓰면 간격을 맞추기 쉽습니다. 영문 너비는 쓴 획의 오른쪽 끝+70 단위, 한글은 1,000 단위입니다. 한글 글자들은 같은 칸 안의 위치를 유지합니다. 현재 버전은 일정한 획 굵기를 사용하며 원본에는 필압도 보존합니다.

## 원본 형식

`.forfont`는 ZIP이며 `manifest.json`(형식·버전·em·기준선·설정)과 `glyphs/<unicode hex>.json`(획 너비와 x/y/pressure 점)을 포함합니다. 글자별 JSON을 순차 처리하고 가져온 원본은 검증 후 폴더 교체로 적용합니다. 직접 쓴 좌표는 기준선과 비율을 유지한 채 TrueType 윤곽으로 변환합니다. 겹치는 획은 합집합으로 처리하며 빈 공간은 보존합니다. TTF는 기기 안에서 생성됩니다. OTF/CFF 출력은 제공하지 않습니다.

## 빌드와 업데이트

Java 17 / Android SDK 35 / Gradle 8.9. `./gradlew assembleRelease`로 빌드합니다. GitHub Actions에서도 unsigned APK를 받을 수 있습니다. 배포 전 반드시 [SIGNING.md](SIGNING.md)에 기록된 원래 서명키를 사용합니다.

핵심 검증: 폰/태블릿 레이아웃, 손가락 무시·펜 취소·실행 취소/복원, 실제 획의 TTF 로드, 원본 왕복. 글꼴 테이블은 Microsoft OpenType 규격에 맞춰 작성하며 FontTools와 FreeType으로 전체 한글 매핑·체크섬을 확인합니다. 실제 S펜의 지연·기기별 팜리젝션 감각은 실기기 확인이 필요합니다.

참고: [OpenType glyf](https://learn.microsoft.com/en-us/typography/opentype/spec/glyf), [Android stylus](https://developer.android.com/develop/ui/views/touch-and-input/stylus-input/advanced-stylus-features).
